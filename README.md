## 📌 Project Overview

The **Retail Sales Forecasting & Inventory Optimization System** is a data science and machine learning project designed to analyze retail sales data, forecast future product demand, and support better inventory management decisions.

The project focuses on understanding historical sales patterns, identifying product performance, analyzing seasonal trends, and helping businesses make data-driven inventory decisions.

It uses Python, Pandas, NumPy, Scikit-learn, Matplotlib, and Streamlit to build a practical retail analytics solution.

## 🎯 Project Objectives

- Analyze historical retail sales data.
- Clean and preprocess raw datasets.
- Identify missing values and duplicate records.
- Analyze daily and monthly sales trends.
- Identify top-performing product categories.
- Forecast future retail sales.
- Support inventory and stock replenishment decisions.
- Present results through an interactive dashboard.

## 🚀 Key Features

1. **Retail Dataset Analysis** – Preview and understand retail data.
2. **Data Cleaning** – Handle missing values, incorrect data types, and duplicate records.
3. **Sales Trend Analysis** – Analyze sales patterns over time.
4. **Category Performance** – Identify top-performing product categories.
5. **Sales Forecasting** – Use machine learning for future sales predictions.
6. **Inventory Optimization** – Support stock and reorder decisions.
7. **Interactive Dashboard** – Visualize key metrics and analytical results.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd Retail-Sales-Forecasting-Inventory-Optimization
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the environment (Windows PowerShell)

```powershell
.\.venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

## ▶️ Run the Project

### Step 1: Generate the retail dataset

```bash
python -m src.data_generation
```

### Step 2: Preprocess the dataset

```bash
python -m src.preprocessing
```

### Step 3: Launch the Streamlit dashboard

```bash
streamlit run app/app.py
```

Open your browser:

```text
http://localhost:8501
```
